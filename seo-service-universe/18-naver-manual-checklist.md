# 18. 네이버 수동 체크리스트 (배포 후)

자동화하지 않는 항목이다. Cursor는 사용자 계정에 로그인하지 않으며 CAPTCHA 우회나 대량 SERP 수집을 하지 않는다.

## A. 배포 직후 (당일)

1. Cloudflare Pages 배포 완료 후, 아래 URL을 브라우저로 열어 200 응답과 본문 표시를 확인한다.
   - /부산가압류신청
   - /부산집행문부여신청
   - /부산채무불이행자명부등재
   - /부산배당요구신청
   - /부산가족관계등록부정정
   - /부산실종선고청구
2. IndexNow는 `npm run indexnow`로 실행한다. 신규·수정 URL만 제출하며 전체 사이트맵 재제출은 하지 않는다.
   - 드라이런(2026-10-04) 결과: 추가 6, 변경 3(/부산시행사등기, /공탁채권회수, /가족후견), 총 9 URL.
   - 실행 후 HTTP 응답 코드를 아래 기록란에 적는다. 200/202는 "접수"일 뿐 색인이나 순위를 뜻하지 않는다.

| 일시 | endpoint | HTTP | URL 수 | 비고 |
|---|---|---|---|---|
| | naver | | 9 | |

## B. Search Advisor (searchadvisor.naver.com) — 사용자가 직접

1. 웹마스터 도구 > 요청 > 웹 페이지 수집에서 아래 16개 URL을 한 번씩 요청한다.
   - 신규 6개: 위 A-1 목록
   - 본문을 보강한 5개: /부산시행사등기, /부산근저당설정등기, /공탁채권회수, /민사소송, /가족후견
   - description을 수정한 5개: /부산휴면법인계속등기, /부산임원사임해임등기, /부산개인사업자법인전환, /예금상속인출절차, /유언공증준비
2. 사이트맵 제출은 기존 sitemap.xml 그대로 둔다. 재제출하지 않는다.
3. 진단 > 사이트 최적화에서 신규 URL에 robots 차단이나 수집 오류가 없는지 본다.
4. 1~2주 뒤 리포트 > 검색 노출에서 신규 URL 노출이 시작됐는지 확인한다.

## D. 사람이 판단할 항목

1. 법인 페이지의 "익명 상담 사례"가 실제 사례인지 확인한다. 사실이 아니면 "이해를 위한 예시"로 문구를 바꾼다 (`14-legal-safety-review.md` 6항).
2. "부산 상속 법무사" 검색에서 /부산상속포기가 계속 대표처럼 노출되는지 본다.
   - 그렇다면 /부산상속포기 본문에 "/부산상속법무사" 역할 링크 1개를 추가할지 결정한다.
   - 현재 노출 중인 페이지라 이번에는 바꾸지 않았다.
3. 임시주주총회 소집허가(서비스 121·122)를 페이지로 만들지 결정한다. 분쟁성 비송이므로 법률 검토 후에만 진행한다.
