# 상속 owner 배포·재수집 체크리스트 (2026-09-21)

## 제출 대상
- `/부산상속법무사`
- `/부산상속포기`

## 배포 직후
- 두 URL이 HTTP 200이고 최종 HTML에 `index,follow`가 적용되는지 확인
- 각 URL의 canonical, Open Graph URL, WebPage·Service·FAQ `@id`가 자기 owner URL인지 확인
- 두 URL이 sitemap에 포함되어 있고 고유 본문·익명 사례·관련 안내 링크가 보이는지 확인
- `/부산상속전문법무사`, `/부산상속포기전문법무사`는 `noindex,follow`와 해당 owner canonical을 유지하는지 확인

## 네이버 서치어드바이저
- URL 검사에서 수집 가능 여부와 대표 URL 판단을 확인
- 위 두 owner만 수집 요청
- 수집 후 색인 상태와 검색 노출을 기록하고, 반복 제출은 피함
