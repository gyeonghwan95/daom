# 수집 소스 매트릭스

수집처의 단일 출처는 `collector/config/sources.ts` 레지스트리입니다.
이 문서는 각 소스의 조사·구현 상태를 기록합니다.

## Phase 1 — 구현 완료 (자동수집)

| 소스 | 공식 URL | 제공기관 | 데이터 | API | 인증 | 수집 방식 | 갱신주기 | 이용조건 | 상태 |
|---|---|---|---|---|---|---|---|---|---|
| 나라장터 입찰공고 (용역) | g2b.go.kr | 조달청 | 용역 입찰공고·마감·금액·지역·첨부 | 공식 Open API | data.go.kr 인증키 | JSON, 게시일시 기간조회, 페이지네이션 | 실시간 | 공공데이터포털 표준약관 | ✅ 구현 |
| 나라장터 입찰공고 (물품) | g2b.go.kr | 조달청 | 물품 공고 중 법무·문서 관련 | 공식 Open API | 동일 키 | 동일 | 실시간 | 동일 | ✅ 구현 |
| 나라장터 입찰공고 (공사) | g2b.go.kr | 조달청 | 공사 부대용역(등기·보상) | 공식 Open API | 동일 키 | 동일 | 실시간 | 동일 | ⏸ 기본 비활성 (데이터량) |
| 누리장터 민간입찰 (용역) | g2b.go.kr (누리장터) | 조달청 | 아파트관리사무소·영리법인 등 민간 용역 | 공식 Open API (`PrvtBidNtceService`) | 동일 키 (**별도 활용신청**) | JSON, 공고게시일시(inqryDiv=2) | 실시간 | 동일 | ✅ 구현 |
| 누리장터 민간입찰 (기타) | g2b.go.kr (누리장터) | 조달청 | 기타 업무구분 민간공고 | 공식 Open API | 동일 키 | 동일 | 실시간 | 동일 | ✅ 구현 |
| 누리장터 민간입찰 (물품) | g2b.go.kr (누리장터) | 조달청 | 민간 물품 | 공식 Open API | 동일 키 | 동일 | 실시간 | 동일 | ⏸ 기본 비활성 |

- 나라장터 엔드포인트: `https://apis.data.go.kr/1230000/ad/BidPublicInfoService/`
- 누리장터 엔드포인트: `https://apis.data.go.kr/1230000/ao/PrvtBidNtceService/`
  - 용역: `getPrvtBidPblancListInfoServc`
  - 필드명이 나라장터와 다름 (`ntceNm`, `nticeDt`, `aptHsmpNm` 등). 아파트단지 정보를 분류에 활용.
- 이관 시 `G2B_API_BASE` 오버라이드 또는 레지스트리 `apiUrl` 수정.
- 웹 원문은 API 응답 URL만 링크로 저장하며 크롤링하지 않습니다.

**누리장터가 중요한 이유:** 나라장터 수요기관으로 등록할 수 없는 발주자(아파트관리사무소, 입주자대표회의, 영리법인 등)의 법무사 선정·등기 용역이 여기로 올라옵니다. 공공입찰만 보면 이 구간이 빠집니다.

## Phase 2 조사 대상 (합법성·중복성 확인 후 단계적 추가)

- 공공데이터포털: 조달청 계약정보·낙찰정보·발주계획·사전규격(HrcspSsstndrdInfoService),
  지자체 계약정보, 공유재산·국유재산, 공공주택·산업단지
- 독립 전자조달: 한국도로공사, 수자원공사, 철도공사·국가철도공단, 한전 그룹,
  HUG, 주택금융공사, 캠코, 한국부동산원, 농어촌공사, 산업단지공단
- 부산 지역: 부산교통공사, 부산시설공단, 부산항만공사, 부산환경공단,
  부산관광공사, 부산 16개 구·군, 지역 대학·공공병원
- 공동주택관리정보시스템(K-apt) 입찰공고, 정비사업 정보공개
- 교육·강의: 지자체·도서관·평생학습관·청년센터 강사 모집

각 소스는 다음 순서로 수집 가능성을 확인한 뒤에만 자동수집으로 전환합니다:
① 공식 Open API → ② 공공데이터포털 데이터 → ③ 공식 RSS →
④ 공식 검색결과 공개 HTML(robots·약관 검토 필수) → ⑤ 이메일 알림 →
⑥ 수동 링크 유지.

## 하지 않는 것

- robots.txt·이용약관을 위반하는 무단 크롤링
- 로그인·인증서·CAPTCHA 우회
- 브라우저 자동화로 비공개 게시판 수집
- 개인 분양자·사건 당사자 연락처 수집
- 자동 입찰서 제출·참가신청
