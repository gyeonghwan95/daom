# 네이버 상속 SEO — 배포 후 확인

순위 보장을 의미하지 않는다. Search Advisor에 나온 숫자만 `seo/inheritance/naver-tracker.csv`에 기입한다.

이번 배포에서 title/H1/URL을 바꾼 오너는 없다. 재수집은 **본문이 바뀐 핵심 URL만**, 남용하지 않는다.

## 1. URL 검사

| URL | 확인할 것 |
|---|---|
| `https://다옴법무사사무소.kr/부산상속법무사` | 수집, 색인, title, description |
| `https://다옴법무사사무소.kr/부산상속포기` | 수집, 색인, title, description |
| `https://다옴법무사사무소.kr/상속` | 색인 유지 (title 변경 없음) |
| `https://다옴법무사사무소.kr/` | 색인 유지 |

기대 title (동결):

- `/부산상속법무사` → `부산 상속 법무사 | 등기·포기·한정승인 먼저 확인`
- `/부산상속포기` → `부산 상속포기 법무사｜3개월 기한과 후순위 상속 효과를 먼저 확인`

`/부산상속전문법무사`는 noindex + canonical `/부산상속법무사`. 색인 대상이 아니다. 삭제·301 확인 요청을 하지 않는다.

## 2. 사이트맵·robots

- Yeti 허용
- sitemap에 `/부산상속법무사`, `/부산상속포기` 포함
- `/부산상속전문법무사`는 sitemap 제외가 맞다

## 3. 최근 90일 query × 노출 URL

숫자를 추정하지 말고 실제 리포트만 적는다.

| query | 기대 owner | 실제 노출 URL | impressions | clicks | CTR |
|---|---|---|---|---|---|
| 부산 상속 법무사 | `/부산상속법무사` | | | | |
| 부산 상속전문 법무사 | `/부산상속법무사` | | | | |
| 부산 상속포기 법무사 | `/부산상속포기` | | | | |
| 부산 상속등기 법무사 | `/부산상속등기` | | | | |
| 부산 한정승인 법무사 | `/부산한정승인` | | | | |
| 부산 법무사 | `/` | | | | |
| 부산 법무사 상담 | `/부산법무사상담` | | | | |

노출 URL이 기대 owner가 아니면 `CANNIBALIZATION_SUSPECT`로 기록하고, 데이터가 쌓인 뒤에만 title 변경을 검토한다.

## 4. 재수집 범위

필요한 경우에만:

1. `/부산상속법무사` (본문·내부링크·선택 UI)
2. `/부산상속포기` (chip/CTA만 바뀜 — 재수집은 선택)
3. `/상속` (intro·링크만 — 재수집은 선택)

HOME title 변경 없음. 홈 재수집을 남용하지 않는다.

## 5. 배포 전 로컬

```
npm run build
```
