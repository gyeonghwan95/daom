# 네이버 로컬 SEO — 배포 후 직접 확인할 일

검색 결과가 바로 바뀐다고 약속하지 않습니다. 아래는 배포 후 사이트 운영자가 Search Advisor에서 확인하는 절차입니다.

## 배포 직후

1. Search Advisor에서 사이트 소유 확인이 유지되는지 본다.
2. `robots.txt`가 수집을 막지 않는지 확인한다.
3. 사이트맵 URL을 다시 제출·확인한다. (정적 배포 기준 `sitemap.xml` / 분할 사이트맵)
4. 핵심 수정 URL을 URL 검사로 수집 요청한다. 우선순위 예:
   - `/연제구법무사`
   - `/수영구법무사`
   - `/동래구법무사`
   - `/부산진구법무사`
   - `/해운대법무사`
   - `/센텀법무사`
   - `/busan-legal-map`
   - 나머지 12개 구·군 허브
5. IndexNow를 쓰는 배포라면 배포 파이프라인 로그에서 제출 실패가 없는지만 본다.

## 7 / 30 / 60 / 90일

`seo/local-ranking-tracker.csv`에 실제 Search Advisor 숫자만 적는다. 추정 숫자·임의 순위는 넣지 않는다.

기록 항목:

- 검색어
- 대표 URL (owner)
- 노출
- 클릭
- CTR

같은 검색어에 여러 URL이 번갈아 잡히면 CANNIBALIZED로 메모한다.

## 해석 주의

- 노출이 이미 있는 페이지는 큰 제목 변경을 반복하지 않는다.
- 데이터가 없으면 SEARCH PERFORMANCE UNKNOWN으로 둔다.
- 이 문서의 체크리스트는 수집·리포트 확인용이며, 순위 보장을 의미하지 않는다.
