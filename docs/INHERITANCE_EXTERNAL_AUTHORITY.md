# 상속 외부 권위 연결 (운영 메모)

Cursor는 네이버 블로그·티스토리·유튜브·플레이스를 직접 수정하지 않습니다.
배포 후 운영자가 아래 매핑으로 외부 설명을 맞춥니다.

## 공식 사이트 역할

- 서비스·판단·절차·상담: 사이트 owner URL
- 사례·질문·해설: 블로그. 공식 owner 장문을 복제하지 않습니다.

## 권장 연결

| 외부 채널 | 상속 종합 글 | 상속포기 글 |
| --- | --- | --- |
| 네이버 블로그 | `/부산상속법무사` | `/부산상속포기` |
| 티스토리 | `/부산상속법무사` | `/부산상속포기` |
| 유튜브 설명 | 해당 서비스 owner URL | 해당 서비스 owner URL |
| 네이버 플레이스 | 홈(`/`) | 홈(`/`) |
