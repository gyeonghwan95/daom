# 상속 외부 권위 링크 — 제안만

이 문서는 **제안**입니다. 외부 사이트에 글을 올렸다고 단정하지 않습니다. 내부 페이지 title/H1/URL을 바꾸라는 지침이 아닙니다.

## 연결하면 좋은 내부 글 (이미 사이트에 있음)

상담·사례 페이지에서 아래를 상황별로 링크하면 됩니다. 앵커는 매번 「부산 상속전문 법무사」로 맞추지 않습니다.

- `/blog/busan-inheritance-registration-procedure-documents` — 상속등기 서류
- `/blog/three-months-after-death-inheritance` — 3개월 경과
- `/blog/minor-heir-inheritance-guide` — 미성년 상속인
- `/services/cases/haeundae-inheritance-registration-case`

## 외부에 올릴 때 (운영자가 직접)

네이버 블로그·지역 커뮤니티에 **새 URL을 만들지 말고** 기존 오너 URL로 안내합니다.

| 주제 | 링크할 오너 | 앵커 예시 |
|---|---|---|
| 등기·포기·한정 중 무엇을 할지 | `/부산상속법무사` | 부산 상속 법무사, 사망 후 절차 선택 |
| 명의이전 서류 | `/부산상속등기` | 부산 상속등기 서류 |
| 빚이 많아 포기 | `/부산상속포기` | 부산 상속포기 3개월 기한 |
| 채무를 모를 때 | `/부산한정승인` | 부산 한정승인 재산·채무 목록 |
| 상담 방법 | `/부산법무사상담` | 부산 법무사 상담 |

외부 글에서 「1위」「최고」「전문 자격」을 쓰지 않습니다. 「부산 상속전문 법무사」는 검색어로 쓰더라도 자격을 표방하지 않습니다.
