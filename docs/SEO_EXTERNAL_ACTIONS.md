# 네이버 SEO — 사이트 밖에서 해야 할 작업

이 문서는 코드 배포만으로 끝나지 않는 작업을 정리합니다. Cursor가 네이버·카카오·유튜브 설정을 바꿨다는 뜻이 아닙니다.

## 네이버 서치어드바이저

1. 사이트 소유 확인이 한글 도메인(`다옴법무사사무소.kr`)과 punycode(`xn--2j1br1na42lvxja38mk8r.kr`) 중 어떤 호스트로 되어 있는지 확인합니다. 사이트 메타·sitemap canonical은 punycode입니다.
2. sitemap 재제출: `https://xn--2j1br1na42lvxja38mk8r.kr/sitemap.xml`
3. 수집 요청(우선) 대상:
   - `/` (부산 법무사)
   - `/부산법무사상담`
   - `/부산법무사추천`
   - `/부산상속법무사`
   - `/부산상속등기`
   - `/부산상속포기`
   - `/부산한정승인`
   - `/부산법무사` (선택 기준, 홈과 다른 의도)
4. `/부산상속전문법무사` 등 브리지 URL은 noindex·canonical 허브로 바뀌었습니다. 서치어드바이저에서 해당 URL이 계속 색인되어 있으면 삭제 요청을 검토합니다. **기존 공개 URL은 사이트에서 삭제하지 않았습니다.**

## 네이버 플레이스

- 상호: 다옴법무사사무소
- 주소: 부산광역시 해운대구 센텀동로 200 D동 1층 LAB9호
- 전화: 홈페이지 푸터·상담 페이지와 동일한 번호
- 홈페이지 링크가 공식 도메인을 가리키는지 확인
- 후기 페이지(`https://map.naver.com/p/entry/place/2035745096?placePath=/review`)와 사이트 `/reviews`가 같은 장소를 가리키는지 확인

## 네이버 블로그

- 프로필 홈페이지 링크 → `https://다옴법무사사무소.kr`
- 서비스 글에서 홈·상담·상속 허브로 **문맥에 맞는** 링크 (키워드만 반복하는 링크 금지)
- 블로그가 「부산 법무사」 대표 문서처럼 보이지 않게, 홈이 사무소 소개임을 프로필에 명시

## 카카오톡 채널 / 네이버 톡톡 / 예약

- 채널 소개에 상호·주소·전화가 홈페이지와 같은지 확인
- 채널 홈페이지 링크

## 유튜브

- 현재 저장소에는 개별 영상 URL만 있습니다. 채널 URL이 확정되면 사이트 `sameAs`에 추가할 수 있습니다.
- 채널 소개란에 공식 홈페이지 링크

## 인스타그램

- 공식 계정 URL이 저장소에 없습니다. 계정이 있으면 홈페이지·`sameAs`에 추가합니다. 없으면 만들지 않아도 됩니다.

## 언론·공공 프로필

- 기존 기사·위원회·강의 소개에 홈페이지 링크를 넣을 수 있는지 각 매체·기관에 확인합니다.
- 링크를 억지로 요청하기보다, 이미 공개된 프로필의 URL 표기만 맞춥니다.

## IndexNow

- 배포 스크립트는 **변경된 URL만** 제출합니다. 성공 응답은 색인 완료가 아닙니다.
- 대량 재전송은 하지 않습니다.

## 하지 말 것

- 검색엔진에 허위 상담 건수·순위·별점을 제출하지 않습니다.
- 네이버 플레이스 상호를 홈페이지와 다르게 바꾸지 않습니다.
- 삭제된 것처럼 보이는 URL을 301로 바꾸지 않습니다. 이번 작업은 slug를 유지합니다.
