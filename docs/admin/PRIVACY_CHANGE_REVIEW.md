# Privacy change review — Admin Ops analytics

작성일: 2026-08-11

## 현재 공개 방침

사이트 개인정보처리방침은 상담·문의 시 수집하는 연락처·상담 내용 중심으로 기술되어 있다. (문의는 Telegram/Resend로 전달, 사이트 DB 미보관.)

## 신규 기능 동작

| 항목 | 내용 |
|------|------|
| page_view / CTA | 경로·유입 host 유형·기기(mobile/desktop) 집계만 |
| 상담 제출 이벤트 | 성공 여부 카운트만 — 이름·전화·메시지 미포함 |
| 공지 | 노출/클릭/닫기 카운트 |
| IP | rate limit용 단기 메모리만, analytics KV에 정확 IP 장기 저장 안 함 |
| fingerprint | 없음 |

## 판단

익명·집계형 운영 통계로, **즉시 법적 문구 자동 추가가 필수는 아님**.  
다만 투명성을 위해 개인정보처리방침에 다음을 **검토·선택적으로** 반영할 수 있다.

> 웹사이트 개선을 위해 페이지 경로·유입 경로 유형·기기 유형 수준의 방문·버튼 클릭 통계를 익명으로 수집할 수 있습니다. 상담 내용·성명·연락처는 해당 통계에 포함되지 않습니다.

## 하지 말 것

- 근거 없는 자동 약관 삽입
- analytics에 상담 본문·연락처 저장
- 쿠키 배너 강제 도입 (현재 first-party 집계·필수 기능 쿠키와 분리된 관리자 세션만 해당)

실제 문구 개정은 사무소 정책·법률 검토 후 진행.
