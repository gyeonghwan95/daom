# 관리자 운영정책

**다옴법무사사무소 관리자 운영정책**

## 1. 관리자

본 시스템의 관리자는 사무소 대표 관리자 1인으로 운영한다.  
관리자 계정은 타인과 공유하지 않는다.

## 2. 접근

관리자 페이지는 인증된 관리자만 접근한다.  
비밀번호·인증정보는 소스코드나 공개 문서에 저장하지 않는다.

## 3. 개인정보

관리 목적에 필요한 최소한의 정보만 확인한다.  
방문통계에는 불필요한 개인정보를 저장하지 않는다.  
상담·문의 정보는 업무 목적 외에 사용하지 않는다.

## 4. 공지

공지사항은 사실에 근거하여 작성한다.  
게시기간이 끝난 공지는 신속하게 종료 또는 보관한다.

## 5. 통계

통계는 사이트 운영 개선을 위한 참고자료로 사용한다.  
수집되지 않은 통계나 검색순위를 임의로 추정하거나 생성하지 않는다.

## 6. 변경기록

공지·설정 등 주요 관리자 작업은 가능한 범위에서 기록을 남긴다.

## 7. 보안

관리자 인증정보, API key, 메일 비밀번호 등은 외부에 공개하지 않는다.  
이상 접근이 의심되면 인증정보를 즉시 변경한다.

## 8. 백업

중요한 운영 데이터와 설정은 Cloudflare KV·배포 파이프라인에 맞는 방식으로 백업한다.  
자세한 내용은 [BACKUP_AND_RECOVERY.md](./BACKUP_AND_RECOVERY.md)를 참고한다.
