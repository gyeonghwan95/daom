# 외부 채널 — 상속 owner 연결 (운영 제안)

Cursor가 외부 사이트를 수정하지 않았다. 아래는 운영자가 직접 할 일.

## 역할

- 네이버 블로그·티스토리: 정보/사례/교육 (DISCOVERY)
- 공식 홈: 신청·상담 owner (CONVERSION)
- 본문 통째 복제 금지. exact commercial 앵커 반복 금지.

## 연결

| 글 주제 | 연결할 공식 URL |
|---------|----------------|
| 상속 종합·무엇을 해야 할지 | `/부산상속법무사` |
| 상속포기 신청·3개월 | `/부산상속포기` |
| 한정승인 | `/부산한정승인` |
| 상속등기 | `/부산상속등기` |
| 사무소 자체 | `/` |

## 채널

1. 네이버 블로그 프로필 → 홈페이지
2. 상속포기 관련 글 → `/부산상속포기`
3. 네이버 플레이스 웹사이트 → HOME
4. 유튜브 프로필 → HOME

티스토리의 「부산 상속 법무사」 글은 삭제하지 않는다. 본문에서 공식 `/부산상속법무사`로 연결한다.
