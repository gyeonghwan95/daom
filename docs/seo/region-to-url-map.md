## 생성하지 않은 표현 (대표 페이지에 흡수)

- 통영시상속등기 → 통영상속등기법무사
- 거제시 상속 법무사 → 거제상속등기법무사
- 울주 상속포기 / 울주군 한정승인 → 울주군상속포기한정승인 (한 페이지)
- 기장 상속포기 → 기장군상속포기
- 마산상속등기·진해상속등기 단독 → 창원 허브 + 구별 기존 페이지
- 사천·남해·고성·밀양 등 2차 후보 → 광역 허브 목록만 (색인 페이지 미생성)

## 혼동 주의

- `/거제동상속등기` = **부산 연제구 거제동** (거제시 아님)
- `/기장상속등기` vs `/기장군상속등기` → 대표는 **기장군상속등기**
