- 마산상속등기·진해상속등기 단독 → 창원 허브 + 구별 기존 페이지

- 고성(검색) → 경남 고성군 페이지 (강원 고성과 FAQ 구분)
- 영천시 농지 상속 → 영천상속등기법무사
- 의령군 상속등기 → 함안상속등기법무사 FAQ에서 흡수 (단독 페이지 없음)
- 영덕군 상속등기 → 울진상속등기법무사 FAQ에서 흡수 (단독 페이지 없음)
- 성주·고령·봉화·영양·울릉 → 단독 페이지 없음 (얇은 콘텐츠 위험, 각 도 허브로 흡수)

## 혼동 주의

- `/거제동상속등기` = **부산 연제구 거제동** (거제시 아님)
- `/기장상속등기` vs `/기장군상속등기` → 대표는 **기장군상속등기**
- 경남 고성군 ≠ 강원 고성군 → `/업무사례/고성군상속등기법무사`에서 구분
- 경북 영주시 ≠ 부산 부산진구 영주동 → `/업무사례/영주상속등기법무사`에서 구분
- 청도군(농지·과수원 중심) ≠ 경산시(아파트·주택 중심) → 두 페이지 모두 FAQ에서 구분
- 경기도 광주시 ≠ 광주광역시 → `/업무사례/경기광주상속등기법무사`(키워드 "경기 광주 상속등기") vs `/업무사례/광주상속등기법무사`(키워드 "광주 상속등기") FAQ로 구분
- 구리시 소형주택 ≠ 서울(노원·중랑·강동 인접) → `/업무사례/구리상속등기법무사` FAQ에서 관할 구분
- 대전 서구(둔산동) ≠ 대전 유성구 → `/업무사례/대전서구상속등기법무사`·`/업무사례/대전유성구상속등기법무사` 상호 FAQ 구분
- 광양 ≠ 여수·순천(생활권 인접, 행정구역 별도) → `/업무사례/광양상속등기법무사` FAQ에서 구분
