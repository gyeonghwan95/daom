## 2. KEEP · IMPROVE · REPOSITION · MERGE · CREATE · TECH-FIX

| 상태 | 대상 |
| --- | --- |
| **KEEP** | `/전국업무`, `/전국상속등기`, `/해외거주상속인`, `/여러지역상속부동산등기`, `/상속상담전준비서류와비용`, 사례·FAQ |
| **IMPROVE** | `/방문없이준비하는상속등기`, `/오래된상속토지정리`, 허브 관련링크·적합도 표(이번) |
| **REPOSITION** | `/방문없이준비하는상속등기` ← “온라인 상속등기” thin 미생성 |
| **MERGE-CANDIDATE (승인 필요)** | 없음 자동 적용. 검토만: 동의어 랜딩이 생기면 허브로 흡수 |
| **CREATE (이미 완료 1~5단계)** | 위 URL 목록 — **이번 요청으로 신규 thin CREATE 없음** |
| **TECH-FIX** | intent 맵 UTF-8 복구; 허브에 A/B/C 표 노출 |

### 승인 대상 (자동 미적용)
- 기존 URL 삭제 / redirect / canonical 통합 / noindex: **해당 없음 제안**
- 충청·호남·강원 권역 허브·도시 상속 원격 클론: **REJECT 유지**
