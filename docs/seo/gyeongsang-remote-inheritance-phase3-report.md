## 생성하지 않음

- 의령(함안 FAQ 흡수), 영덕(울진 FAQ 흡수) — 단독 페이지로는 콘텐츠가 얇아질 위험
- 성주·고령·봉화·영양·울릉 — 요청 범위 밖, 각 도 허브 목록에서만 링크
- 비용·서류 지역 복제 페이지 — 신규 생성하지 않음(기존 전국 비용·서류 안내로 흡수)

## 잠식 방지 체크

- **primaryKeyword**: 11건 모두 서로 다름 (예: 산청=`산청 임야 상속등기`, 거창=`거창 비대면 상속등기`, 합천=`합천 농지 상속등기`처럼 지역명 기반 기본형과 차별화된 키워드 사용)
- **seoTitle**: phase1/phase2 템플릿 접미사("｜상속인이 타지역에 있어도 준비하는 방법", "｜부산 방문 없이 맡기는 방법", "｜토지·농지 상속 절차")를 그대로 쓴 페이지 없음. 각 페이지가 지역 고유 상황(생활권 분산, 관할 등기소 차이, 동명 지역 구분 등)을 제목에 반영
- **h1**: 11건 + 기존 전체 페이지와 완전히 다른 문구. "OO 상속부동산을 부산 방문 없이 맡기는 방법" 패턴 미사용
- **metaDescription**: 11건 모두 첫 40자가 서로 다름(지역명·상황이 즉시 구분되도록 작성)
- **FAQ 질문**: 11건 내에서 완전히 동일한 질문 문자열 없음(지점 안내형 질문도 지역명이 앞에 붙어 문자열 자체가 다름)
- **scenarioTitles**: 11건 내에서 완전히 동일한 문자열 없음
- **heroDescription**: 전부 320자 이상, 지명·절차·관할 등기소/지원명을 구체적으로 명시
- **jurisdictionNote / legalScopeNotice**: 전부 100자 이상, 등기소(부동산 등기)와 가정법원(상속포기·한정승인) 관할이 다른 경우를 사실 기반으로 안내(창원지방법원 밀양·마산·진주·거창지원, 대구지방법원 상주·안동·영덕지원, 대구지방법원 본원 등 실제 관할구역 확인 후 작성)
- **금지 표현**: "상위노출 보장", "무조건 상위", "전국 최저", "무조건 비대면" 등 과장 표현 미사용. ctaDescription도 페이지마다 다르게 작성해 CTA 문구 복제 없음
