## 2. KEEP · IMPROVE · REPOSITION · MERGE · CREATE

- **KEEP**: 위 전국·상속·사례 핵심 URL
- **IMPROVE**: `/전국업무`, `/여러지역상속부동산등기`, `/해외거주상속인`, `/상속상담전준비서류와비용`, `/방문없이준비하는상속등기`
- **REPOSITION**: `/방문없이준비하는상속등기` (공동상속인 분산 의도 → 신규 URL로 이전)
- **MERGE-CANDIDATE**: 없음 (신규 thin 미생성). `/전국비대면법무사업무범위` 별도 생성 안 함
- **CREATE**: 아래 6 URL
- **TECH-FIX**: 신규 URL sitemap·self-canonical·여정맵 등록 (이번 작업). IndexNow는 **배포 후**

## 4. 프로젝트에 없던 검색 의도 (1단계만 생성)

1. 방문 전 확인 가능한 법무사 업무 범위(지역 비의존 허브)
2. 공동상속인 **거주지** 분산
3. 부동산 소재지 ≠ 상속인 거주지(전국 일반, 경상도 특화와 분리)
4. 상속포기·한정승인 방문 전 준비·기한
5. 사진·전자파일·우편 서류 전달
6. 업무 횡단 비용 확인 방법
