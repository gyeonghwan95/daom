# 경상도 비대면 상속 SEO — 1차 완료 보고 (2026-08-01)

## 요약
지역명만 바꾼 대량 복제 없이, **누락·고유 의도**만 CREATE하고 기존은 IMPROVE.
신규 공개 7페이지 + 기장 포기/한정 local-landing 승격 + RegionalRemoteInheritance 적용.

## 3. 분류

| 구분 | 대상 |
|---|---|
| KEEP | 김해·양산·창원·진주·울산·경북 도·전국 허브 |
| IMPROVE | 거제등기, 울주등기, 기장포기/한정, 경남법무사업무 링크, `/상속` 지역 섹션 |
| CREATE | 위 7 URL |
| MERGE-CANDIDATE (승인 대기) | `/기장상속등기` vs `/기장군상속등기`; `/거제동*`는 부산(별의도) |
| CREATE 보류 | 마산·진해 단독, 사천·남해·고성·밀양·안동 등 2·3차 |
