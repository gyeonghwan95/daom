# 부산 건물·법인 등기 검색 의도 맵 (1차)

기존 URL은 삭제·변경하지 않는다. 동의어는 대표 URL에 흡수한다.

## 건물 클러스터

| 대표 URL | 주 키워드 | 흡수 키워드 | 비고 |
|----------|-----------|-------------|------|
| `/부산건물등기` | 부산 건물등기 | 건물등기 법무사, 건축물 등기 안내 | 대형 허브 |
| `/부산건축물등기법무사` | 건축물등기 법무사 | 건물등기 상담 | 상담 각도 |
| `/부산건물멸실등기` | 건물멸실등기 | 건축물멸실, 철거등기, 멸실등기 법무사 | 멸실 허브 |
| `/부산신축건물보존등기` | 신축 보존등기 | (기존) | **보강만** |
| `/부산건물표시변경등기` | 건물표시변경등기 | 면적변경, 구조변경 등기 | ≠명의인표시변경 |
| `/부산집합건물등기` | 집합건물등기 | 구분건물 등기 | → `/집합건물보존등기` 연결 |
| `/부산공장창고등기` | 공장·창고 등기 | 공장보존, 창고등기 | |
| `/건물등기상황별안내` | 상황별 건물등기 | | 종합 허브 |

### 멸실 상세 → 상위 `/부산건물멸실등기`

철거후멸실등기, 건축물대장말소와멸실등기차이, 멸실등기없이토지매도, 신축전기존건물철거등기순서, 화재소실건물멸실등기, 건물일부철거표시변경, 공장철거후멸실등기, 상속건물멸실등기, 건축물대장말소등기부잔존, 등기부존재실제건물없음, 공유자연락두절멸실등기, 건물토지소유자상이멸실

### 생성 제외 (통합)

다가구·공동주택·집합 보존 전용 URL, 구명만 바꾼 멸실 복제, `부산법인설립*` 추가

## 법인 갭

상호변경, 지점설치/폐지, 감자, 무상증자, 휴면계속, 공동대표, 사임해임, 개인사업자법인전환, 해산전확인, 녹산산단본점지점
