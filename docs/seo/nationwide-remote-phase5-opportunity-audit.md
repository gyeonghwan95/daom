## IMPROVE (CREATE와 동시)

- `/민사소송`, `/공탁채권회수` contact → 신규 URL
- situations: 내용증명 수신↔발신, 대여금/강제집행/공동명의 → 해당 서류 URL
- 부산 이혼·압류말소·상속후매매 ↔ 신규 전국 서류
- remote-service-matrix 행 추가
- 원격 종합 허브 related 링크 확장

---

## REJECT

- 충청/호남/강원 권역 상속 허브
- 추가 시군 상속·비대면 동의어
- 부부간증여·지분증여·보존·멸실·경매·신탁 remote 클론
- 가처분 유형 시리즈·가처분말소 단독
- 비영리 발기인 분산 (특수법인 클러스터와 충돌)
