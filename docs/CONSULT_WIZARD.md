# 단계형 상담하기 (Consult Wizard)

기존 `/api/quick-inquiry`(Resend·Turnstile·honeypot·rate limit)를 **재사용**합니다.  
기존 URL·canonical·콘텐츠는 변경하지 않았습니다.

## 흐름

1. 상황 복수 선택 (+ 선택 메모)  
2. 상황별 서류 복수 선택 (`아직 준비된 자료가 없어도…` 포함)  
3. 성함·연락처·선호 연락·시간·동의  
4. 요약 확인 → 이메일 문의 제출  

성공 시: 전화 / 내용 다시 보기 / 홈  

## 진입점

- 데스크톱 플로팅 「상담하기」 패널 (전화·카카오·톡톡 유지, 간편문의 단독 버튼 제거)
- 모바일 하단 「상담」
- 인라인 카드·유입 랜딩 「약 1분 간편 상담」
- 페이지 맥락에 따라 상황 자동 추천 (`suggestSituationsFromPath`)

## 신규 유입 URL

`/상담`, `/1분간편상담`, `/법무사상담`, `/상속등기상담`, `/상속포기상담`, `/한정승인상담`, `/부동산등기상담`, `/법인등기상담`, `/전세보증금상담`, `/개인회생상담`, `/등기서류상담`, `/무슨법률업무인지모를때`, `/서류가없어도상담가능`, `/전화가어려울때법률상담`

## 분석

`trackConsultEvent` — 시작/단계/완료/이탈만. 이름·연락처·메모 **미전송**.
