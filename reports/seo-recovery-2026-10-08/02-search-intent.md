# B. 검색 의도 (메인 에이전트 분리 검토)

관측 사실
- 사용자 14개 최초 후보 URL은 live 200·고유 title/H1·self-canonical.
- `/`는 이미 부산 법무사 소개와 업무 링크가 있다.
- `/부산법무사`는 홈과 다른 업무 선택 페이지로 존재.
- `/상속`은 전국 종합, `/부산상속법무사`는 부산 분기.
- `/부산법인전문법무사`·`/부산등기전문법무사`는 noindex 관측(기존).
- 네이버 일반검색 14개 결과는 이 세션에서 로그인/PC·모바일로 확인하지 못함.

원인 가설
- 대표 URL 부재가 아니라, 같은 템플릿 반복과 허브 간 역할 흐림이 더 크다.
- 기간/기한 301 통합은 다른 검색어 세트 분석이므로 이 과업에 쓰지 않는다.

증거
- `.cache/live-seo-baseline.json`
- `src/lib/local-landing/flagship-busan-lawyer.ts`
- `src/lib/local-landing/registry-hub-content.ts`
- `src/lib/local-landing/company-establishment-busan.ts`

영향 URL
- 14개 최종 대표는 `14-keywords.json` 참고.

해결안
- 후보 URL을 최종 대표로 확정(canonical 강제 병합 아님).
- 동의어(전문, 어순 반전)는 기존 대표에서 충족.
- `/법인등기`에 설립 대표 링크 보강.
- `/상속` 요약이 부산 검색을 `/부산상속법무사`로 안내하되 전국 허브 역할을 유지.

효과의 근거
- 한 의도 한 대표, 기존 유입 URL 보존. 순위 공식으로 쓰지 않음.

부작용
- 09(부산 법무사 상속) SERP가 전국 허브를 더 선호하면 오배정일 수 있음 → 미확인으로 남김.

검증법
- 14행 자동 테스트.
- 대표 URL 삭제 0.

미확인
- 네이버 14개 검색 결과, site: 색인 목록, 서치어드바이저 유입.

이 관점의 최선안: 기존 후보 URL을 대표로 고정하고 페이지 역할을 본문·링크로만 분명히 한다.
