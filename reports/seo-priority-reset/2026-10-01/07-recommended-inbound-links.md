# 07. 추천 inbound link (이번 작업에서는 적용하지 않음)

브리프 규칙에 따라 target 밖의 indexable 페이지는 수정하지 않았다(NON_TARGET_CHANGED_URLS = 0). 아래 링크는 다음 작업에서 사람이 검토한 뒤 넣을 후보다. 각 페이지 본문 흐름에 맞는 문장 안에서 한 번만 연결한다.

| 출발 페이지 (비대상) | 도착 target | 넣을 위치 | 앵커 예시 |
|---|---|---|---|
| /공탁자가진단 | /부산공탁 | 진단 결과 아래 | 공탁 종류별 안내 |
| /공탁채권회수 | /부산집행공탁 | 제3채무자 공탁 언급 문단 | 제3채무자 집행공탁 |
| /공탁채권회수 | /공탁금출급회수 | 공탁금 수령 문단 | 공탁금 출급·회수 |
| /변제공탁서류준비 | /부산변제공탁 | 첫 문단 | 변제공탁 요건과 공탁소 |
| /부산상속법무사 | /부산한정승인 | 빚이 걱정될 때 문단 | 한정승인 판단 순서 |
| /부산상속법무사 | /부산상속전문법무사 | 사무소 선택 문단 | 상속 법무사 선택 기준 |
| /특별한정승인 | /부산한정승인 | 3개월 안인 경우 안내 | 3개월 안이라면 한정승인 |
| /상속포기후다음순위확인 | /부산상속포기 | 첫 문단 | 부산 상속포기 신고 |
| /부산법무사비교 | /부산법무사추천 | 비교 기준 문단 | 법무사 선택 기준 7가지 |
| /부산법무사방문상담, /부산법무사비대면상담 | /부산법무사상담 | 상단 안내 | 처음 연락하는 방법 |
| / (홈) | /부산법무사 | 업무 안내 영역 | 부산 법무사 업무 안내 |
| / (홈) | /부산공탁 | 업무 목록 | 공탁 |

주의: 홈은 '부산 법무사' 검색에 이미 노출되고 있으므로, 홈 title·H1은 건드리지 않고 링크 한 줄만 검토한다.
