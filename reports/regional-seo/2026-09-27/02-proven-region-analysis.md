# 02. 이미 노출되는 지역(울산·포항) 공통 원리

기준일 2026-09-27. SERP는 로그아웃 상태 1회 표본이며 순위를 보장하지 않습니다. Search Advisor 데이터가 없어 노출·클릭 수치는 쓰지 않았습니다.

## 결론

"페이지가 많아서"가 원인이 아닙니다. 대구는 하위 문서가 약 25개인데 1페이지에 없고, 포항은 하위 문서가 적은데 1위였습니다. 코드로 확인한 구조적 차이는 아래 네 가지입니다.

| 요소 | 울산 | 포항 | 대구(미노출) |
|---|---|---|---|
| 강한 내부 경로 | 푸터(약 1,800쪽)에서 `울산법무사업무` 허브 링크 → 허브가 상속 문서로 연결 | 상속 허브 `/상속`와 경북 허브에서 직접 링크 | `대구법무사업무` 유입 24건, `/상속`·푸터 링크 없음 |
| SERP 짝 노출 | 허브 + 아파트 상속 문서 | 도시 문서 + 경북 상위 허브 | — |
| 제목 | 지역 + 상속(등기) + 법무사 | 지역 + 상속등기 + 법무사 | 지역 + 상속등기 + 법무사(동일) |
| 상위 경쟁 | 광고·플레이스 다음 1위 | 광고·플레이스 다음 1위 | 현지 사무소 다수 |

제목 패턴은 대구도 같으므로 제목만으로는 설명되지 않습니다. 차이가 가장 큰 것은 **사이트 안에서 그 지역 문서로 들어오는 강한 경로**와 **현지 경쟁 강도**입니다.

## 공통 요소 (다른 지역에 적용 가능한 원리)

1. 지역 + 업무 + 법무사가 제목 앞부분에 있음.
2. H1이 원격 의뢰 질문형("부산 방문 없이 맡기는 방법", "어디서 상속등기를 받을까")으로 제목과 역할이 다름.
3. 사이트 전역에서 2클릭 이내로 닿는 내부 경로(푸터 허브 또는 `/상속`).
4. 상위 허브(경북·울산 허브)와 도시 문서가 서로 링크 → 네이버가 두 문서를 묶어 보여줌.
5. 경쟁이 적은 SERP(광고·플레이스 외 웹문서 경쟁이 약함).

## 복제하면 안 되는 요소

- 공통 템플릿 반복: 울산 대표 문서의 정규화 유사도 0.7537(HIGH), 포항 0.6928(REVIEW), 중복 문장 9건/17건.
- 푸터 지역 목록 확대: 브리프 금지사항(푸터 지역 나열). 대신 푸터에 이미 있는 `/전국상속등기`에서 큐레이션 링크로 연결했습니다.
- 검증되지 않은 문구("포항 … 사례가 많습니다" 등).

## 이번 배치에 적용한 방식

- 푸터에 이미 링크된 `/전국상속등기`에 지역 대표 URL 12개를 서로 다른 앵커로 연결(허브 → 도시).
- 각 도시 문서는 `/전국상속등기`와 도시 하위 문서(비용·서류·상속포기)로 링크(도시 → 허브·클러스터).
- 도시마다 법원 관할 차이 등 검증 가능한 고유 정보로 본문을 새로 작성(유사도 0.72–0.77 → 0.065–0.083).
