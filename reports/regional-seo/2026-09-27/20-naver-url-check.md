## 순서

1. 배포 후 각 URL을 브라우저에서 열어 title·H1이 위와 같은지 확인.
2. 서치어드바이저 → 웹마스터 도구 → 요청 → 웹 페이지 수집에 6개 URL 입력.
3. 검증 → 웹 페이지 최적화(또는 URL 검사)로 robots 허용·canonical self·og:image 로드 확인.
4. 사이트맵은 이미 제출된 `sitemap.xml` 그대로(재제출 불필요, lastmod가 6개만 2026-09-27로 바뀜).
5. 1–2주 뒤 "양산 상속 법무사", "창원 상속 법무사", "김해 상속 법무사", "대구 상속 법무사", "거제 상속 법무사"를 로그아웃 상태로 검색해 노출 URL을 기록.

## 제출하지 않는 URL

- 울산·포항·경산(PROTECT_WINNER, HTML 변경 없음): 재수집 요청 불필요.
- NCR 대상 3개(`/부산상속전문법무사`, `/부산상속포기`, `/해운대법무사`): 이번 작업에서 변경 없음. 이전 작업 목록으로 제출합니다.
- 그 외 1,651개 보호 URL: HTML·lastmod 변경 0.
