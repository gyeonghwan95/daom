# 12. 생성·개선 계획

## Batch A (이번 배치, 완료)

신규 URL 0개, 기존 대표 URL 5개 개선 + 전국 허브 1개 보강. `MAX_NEW_REGION_PAGES_PER_BATCH = 5` 안에서 신규 대신 개선을 택했습니다. 평가한 23개 지역 모두 대표 URL(`/업무사례/{지역}상속등기법무사`)이 이미 있어, 새 URL은 같은 의도를 나눠 갖는 cannibalization이 되기 때문입니다.

| URL | 고유 각도 | H2 구성 |
|---|---|---|
| `/업무사례/양산상속등기법무사` | 방문·비대면 혼합, 상속포기는 울산가정법원 | 방문/비대면 비교표 → 등기 특례 vs 포기 법원 → 부산·양산 상속인 → 신축 아파트+외곽 토지 → 원본 → 비용 → 예시 |
| `/업무사례/창원상속등기법무사` | 5개 구 일괄 신청(제7조의2·7조의3), 구별 가정법원 | 두 근거 카드 → 구별 관할표 → 구별 목록(구 문서 5개 링크) → 타지역 상속인 → 비용 → 예시 |
| `/업무사례/김해상속등기법무사` | 부산 사는 상속인 순서, 공장·농지, 창원지법 본원 | 4단계 순서 → 관할 → 부동산 종류 카드 → 방문 필요 경우 → 비용·취득세 → 예시 |
| `/업무사례/대구상속등기법무사` | 부산 사무소 vs 대구 현지 선택 기준(솔직한 비교) | 선택 기준표 → 비대면 순서 → 관할(군위군 주의) → 구·군 다수 부동산 → 원본 → 비용 → 예시 |
| `/업무사례/거제상속등기법무사` | 경남 거제시 vs 부산 거제동 구분, 통영지원 | 구분표 → 원격 이유 → 통영지원 → 시내 아파트+면 토지 → 원본 → 비용 → 예시 |
| `/전국상속등기` | 지역 큐레이션 12개, 과장 FAQ·인트로 정정 | 기존 구조 유지 + "지역별 상속등기" 섹션 1개 |

공통 규칙: 제목(검색어 매칭)과 H1(질문형) 역할 분리, 지역별 FAQ 5개 고유, CTA는 "여기서 맡길 수 있는지"를 먼저 답하고 최소 입력 항목만 요청, 지점 없음·부산 해운대 사무소 고지, 경험 항목은 EXAMPLE_ONLY로 표기, 실제 사무소 사진 크롭으로 og:image 고유화, schema는 WebPage·BreadcrumbList(+기존 사이트 공통 Organization)만.

## Batch B (다음 배치 제안, 승인 후)

경주 → 진주 → 구미 → 통영 → (울주군 또는 밀양). 모두 기존 대표 URL 개선. 각 도시의 가정법원 관할은 페이지에 쓰기 전 법원 관할표로 재확인합니다(레지스트리에 "재확인 필요"로 표시).

## 만들지 않는 것 (DO_NOT_CREATE)

- 키워드 변형 URL(예: "울산 상속 법무사"용 별도 URL): 기존 대표 URL과 경합.
- 동·읍 페이지 추가: 이미 THIN_LOCAL_PAGE 40건.
- 조합 페이지(서울상속인경남부동산 등).
