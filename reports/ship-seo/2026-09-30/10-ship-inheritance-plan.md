# 10. 선박상속 페이지 (`/선박상속`)

## 역할

"선박상속", "선박상속 법무사", "선박 상속등기", "부산 선박상속", "어선 상속"의 대표 URL. 별도 부산 선박상속 URL은 만들지 않았다.

## 검색 의도 → 구성

| 사용자 질문 | 섹션 |
|---|---|
| 아버지 배, 무엇부터? | 첫 두 문단 직접 답변 + 먼저 확인할 네 가지 + 크기별 절차 표 |
| 어선인데 기한은? | 어선 섹션 — 시행규칙 제26조 6개월, 어업허가는 별도 |
| 형제가 같이 받으면? | 공동상속 — 단독 협의 vs 공유, 지분 기재(규칙 제13조) |
| 미성년 자녀가 있으면? | 특별대리인(민법 제921조), 일정 충돌 주의 |
| 관리인이 필요한가? | 상법 제764조·제765조 요약 → `/선박관리인선임등기` |
| 서류·세금 | 6단계 순서, 취득세 6개월/9개월(지방세법 제20조), 세율은 단정 안 함 |
| 빚이 걱정되면? | FAQ — 처분은 단순승인 의제(민법 제1026조) 경고 |

## 품질 기준

- title "선박상속 법무사｜선주가 사망했다면 등기·원부·관리인 순서로", H1은 질문형으로 title과 분리.
- 첫 700자는 "안녕하세요"로 시작하지 않고, 다른 선박 페이지와의 최대 유사도는 `18-pages-created.csv` 참고.
- 사례 섹션은 "검증된 선박상속 사례를 아직 싣지 않았다"고 명시(경험 과장 없음).
- CTA 1곳(상담 문의 + 전화 1개). 개인정보 입력 요구 없음.
- 울산·포항 상속 PROTECT_WINNER 페이지는 건드리지 않음.
