# 11. 선박관리인 페이지 (`/선박관리인선임등기`)

## 단독 페이지로 만든 이유

- 표본 SERP("선박관리인 선임")가 사전 정의·서식 위주라 절차 설명 문서가 비어 있음.
- 공유 선박·공동상속에서 반드시 따라오는 절차인데 상속 페이지 안에 넣으면 상속 페이지가 길어지고 의도가 섞임.
- 목표 길이 1,800–3,000자 범위.

## 구성

1. 관리인의 권한 — 상법 제764조(선임·전원 동의·등기), 제765조(재판상·재판 외 권한).
2. 누가 신청하나 — 선임·변경·대리권 소멸 등기의 신청인 표(선박등기규칙 제17조–제19조).
3. 공동상속 뒤 관리인 — 실제 운항자를 관리인으로, 공유자 아닌 사람은 전원 동의.
4. 소형선박 — 법원 등기부가 없어 관리인 등기도 없음(선박등기법 제2조 범위 밖).

## 연결

- 상위: `/선박등기`
- 형제: `/선박상속`(공동상속 섹션에서 링크), `/통영선박등기`(공동상속 지역 사례)
