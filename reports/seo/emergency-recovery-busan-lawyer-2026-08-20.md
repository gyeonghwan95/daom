# 비상 복구 — 부산 법무사 / 추천 / 상담 (2026-08-20)

## 진단 요약 (확인된 사실만)

1. HOME title이 `부산 다옴법무사사무소 | 안윤정 법무사`로 바뀌며
   Exact-match 「부산 법무사」가 title에서 빠짐 → PRIMARY 신호 약화.
2. `/부산법무사`도 supporting title이라 broad exact를 양쪽에서 잃음.
3. 사이트 검색 alias가 `/부산법무사*`에 「부산 법무사」「법무사 추천」을
   섞어 추천·상담 페이지와 충돌.
4. 웹 검색 결과에서 law-yoon.tistory.com 이 같은 키워드로
   공식 사이트와 경쟁 (외부 카니발). 코드로 티스토리 수정 불가.

순위 숫자는 네이버 SERP 자동 확인 없이 단정하지 않음.
1~3위 보장은 불가능. 복구는 Exact-match·역할 분리·alias 정리.
