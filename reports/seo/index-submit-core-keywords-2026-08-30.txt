## 제출하지 않는 것

- 비용 전용 URL(`/부산법무사비용`, `/상속포기비용` 등): 이번 배포에서 본문 미변경
- 16개 구·동 지역 페이지
- `/상담` 위저드, `/contact/inquiry?…`
- `/admin`, 미디어, noindex

## 제출 메모

- 반드시 **이번 코드가 올라간 배포 이후**. 로컬만이면 색인 실패.
- IndexNow: `npm run indexnow:dry` → 배포 → `npm run indexnow`
- 네이버 서치어드바이저: P0를 URL 검사 → 수집 요청 1회. 같은 URL을 며칠 간격으로 반복 제출하지 말 것.
- Title/Description을 제출 때문에 다시 바꾸지 말 것.
- 순위 보장 없음. 수집·색인 여부만 확인.
