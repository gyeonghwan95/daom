# 06 Content gap

경쟁 상위 웹문서는 네이버 CAPTCHA로 구조 크롤을 하지 않음.  
갭은 **검색자가 추가 검색 없이 결정할 수 있는가**와 production HTML·내부 페이지만으로 추출.

글자 수 경쟁은 목표가 아님.

## `/` 부산 법무사 — PROTECT-A

이미 title/H1이 쿼리와 맞음. 엔티티(안윤정·해운대·센텀·후기·사례·언론)가 HOME에 있음.  
이번: title/H1 유지. 홈 허브 라벨에서 “검색” 표현과 exact-match 반복만 줄임.

## `/부산법무사상담` — REBUILD-C (구조) / IMPROVE-B (고유문)

**갭:** 행동 페이지인데 15개+ 목차, hero·요약·자세히·추가 섹션이 같은 안내를 3~4회 반복.  
“검색어 나열/상담·추천·사무실 검색 구분” 섹션이 사용자 SEO 용어로 보임.

**보완(삭제 없이 정리):**
1. 어떤 문제인가요?
2. 처음 알려주실 정보
3. 안윤정 법무사
4. 상담 방법
5. 업무별 기본 자료
6. 초기 안내와 정식 수임
7. 비용 확인
8. FAQ

고유 법률광고 범위(법무사법 제2조)는 유지.

## `/부산법무사추천` — PROTECT-A + 문구

선택 기준 방향은 이미 맞음.  
갭: “검색의도 안내”, “검색 전에” 등 내부 용어. 사용자 문장으로만 교체. 본문 대량 삭제 없음.

## `/부산등기법무사` — IMPROVE-B

이미 상황 분기·진행·서류·사례·관할·비용이 있음. 단순 링크허브가 아님.  
갭: FAQ 한 줄(“해당 안내로 연결합니다”)이 허브 전용처럼 들림 → 가등기·대지권도 등기업무라는 완결 문장으로 교체.

## `/부산상속법무사` — PROTECT-A

등기·포기·한정 선택 허브로 이미 정합.  
갭: 상단 분기 링크에 해외·미성년·협의분할을 더함. title/H1 변경 없음. “검색어 나열” 문구 제거.

## `/부산상속포기` · `/부산한정승인` — PROTECT-A

기한·후순위·채무조사 초점이 이미 강함. 일반 상속등기 설명으로 분량을 늘리지 않음.  
부모 허브로 돌아가는 링크가 이미 있음.

## `/부산부동산등기` — PRIMARY (부산 부동산 법무사)

기존 unique URL. `/부산부동산법무사` 생성 안 함.  
갭: 매매·증여·상속·근저당·전세권·보존 **상황 내비게이터**가 약했음 → 상단 섹션 추가.  
exact phrase “부산 부동산 법무사” 본문 반복 없음.

## 경쟁 구조에서 본 공통 질문 (사이트 내부로 이미 담당)

| 질문 | 담당 URL |
|---|---|
| 누구·어디 사무소인가 | `/` `/about` `/location` |
| 상담 채널 | `/부산법무사상담` |
| 고르는 기준 | `/부산법무사추천` |
| 어떤 등기인가 | `/부산등기법무사` |
| 상속 무엇을 먼저 | `/부산상속법무사` |
| 3개월·후순위 | `/부산상속포기` |
| 재산목록·후속 | `/부산한정승인` |
| 매매·담보·보존 | `/부산부동산등기` |
| 비용 구성 | 기존 비용 URL + 각 페이지 비용 섹션 |

신규 랜딩(`/부산법무사등기`, `/부산상속전문법무사` 등) 불필요.
