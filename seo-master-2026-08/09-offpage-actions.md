# 09 Off-page actions

외부 서비스는 자동 수정하지 않음. 링크 구매·스팸 백링크 금지.

## 공개 범위에서 확인된 엔티티

사이트 내부·공식 프로필 기준:

- **상호:** 다옴법무사사무소
- **대표:** 안윤정 법무사
- **소재:** 부산광역시 해운대구 센텀동로 200
- **혼동 위험:** 연제구 거제동 **법률사무소 다옴**(변호사)와 상호가 비슷함. 네이버 플레이스·웹문서에서 구분 필요

## OFFPAGE-ACTIONS (사용자)

1. **네이버 서치어드바이저** — 아래 P0 9 URL 수집·색인·수집 title/canonical 확인. 권한 없이는 대행 불가.
2. **네이버 플레이스** — 상호·주소·전화·카테고리(법무사)가 사이트 NAP과 동일한지 확인. 연제구 변호사 사무소와 혼동 설명(업종·주소) 점검.
3. **네이버 블로그·톡톡** — 프로필명 `다옴법무사사무소` / `안윤정 법무사` / 부산 해운대·센텀 일관.
4. **언론·강의·기관 페이지** — 사이트에 이미 있는 실제 기사·강의만 원문 링크 유지. 신규 홍보성 백링크 제작 금지.
5. **IndexNow / 사이트맵** — 기존 제출 절차만. sitemap priority 조작·매일 lastmod 금지.

## 하지 말 것

- 후기·별점·성공률 조작
- “부산 1위” 등 비교 광고
- exact-match 앵커로 된 대량 외부 디렉터리 등록
